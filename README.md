### 🚀 Featured Project

**[✈️ Singapore Airlines Customer Intelligence (NLP)](https://github.com/Vinil247/singapore-airlines-nlp-analysis)**
*An end-to-end NLP pipeline decoding the "Voice of the Customer" from 10k+ reviews.*

| **The Engineering** | **The Strategy** | **The Impact** |
| :--- | :--- | :--- |
| **Semi-Supervised Learning:** Zero-Shot Pseudo-Labeling + Confidence Thresholding. | **Mixed Sentiment Discovery:** Logic-based detection of complex reviews (Praise + Complaint). | Recovered **15% of data** typically discarded by standard models. |
| **Fine-Tuning:** DistilBERT & RoBERTa optimized with **Focal Loss** for class imbalance. | **Impact Index:** Custom metric blending Topic Frequency × Net Sentiment. | Identified **Refunds (-612)** as the #1 churn driver post-pandemic. |

**Stack:** `PyTorch` `Transformers` `BERTopic` `WandB` `Focal Loss` `Pandas`
